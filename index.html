WorkBuddy 用前先改这 8 个设置

阿胜的小栈 · 原创整理 · 2026-11-10 · 路径按个人版帮助文档核对

一键复制：自定义指令全文（约 298 字，粘进 设置 → 个性化 → 自定义指令）

刚用 WorkBuddy 的那几天，很多人都会卡在两件小事上：问一句，它回一大段；交代个活，它先连环追问五六个问题。

不是它不行，是默认设置没改。这篇只讲个人版里确实存在的 8 个设置，每一项都写清完整路径和为什么改，再给你一段能直接粘贴的自定义指令。照着做，大约 10 分钟。

先找到设置入口

• 已登录状态：点左侧边栏最底部的头像 → 设置。设置会以独立窗口打开，不影响主窗口里正在跑的任务。

• 也可以从顶部工具栏 帮助 → 设置 打开。

• 所有修改即时生效，不用重启。

• 找不到某一项时，用设置窗口左侧导航顶部的「搜索设置项」，输入中文名或关键词（比如「提示音」「代理」）即可跳转。

8 个设置，按影响从大到小

① 回复风格＋自定义指令

路径：设置 → 个性化

左侧导航「功能」分组 → 个性化。这里有回复风格、称呼与身份、自定义指令等选项。

自定义指令是全局规则，写一次，之后每个新对话都会带上。输入框上限约 1500 字符，下面这段约 300 字，留足了你自己加内容的空间。

【我的使用习惯】（整段复制，粘进「自定义指令」）

1. 用中文口语回答，先给结论再说理由；一句话能说清的，别写一大段。

2. 接到任务先确认四件事：目标是什么、交付什么（表格、文档还是清单，放在哪个文件夹）、有什么限制（哪些文件不能动、什么时候要）、做到什么程度算完成。

3. 信息不够时，先自己翻我给的文件和之前的对话找答案；实在找不到的，一次性列出来集中问我，不要一条一条追问。

4. 删除、覆盖、移动文件，或者对外发送内容之前，先列清单等我确认。

5. 做完先自查：对照我的要求逐条打勾，告诉我哪里没做到、哪里需要我人工核对。

6. 不确定就直接说不确定，不编数字、不编出处。

7. 我说得不对也请直接指出，不用顺着我说。

粘贴后点确认保存。验证方法：新开一个对话，交代一个小任务，看它是不是先给结论、问题一次问完、动文件前先列清单。

换个身份：把这一句加在最前面

上班族

我是做行政和运营的上班族，常处理表格、周报和会议纪要。表格默认做成 Excel，周报按「本周完成、遇到的问题、下周计划」三段写，每段不超过5条。

学生

我是大二学生，主要用来整理笔记、复习和写课程报告。讲知识点先打一个生活里的比方再讲定义；帮我看作业时只指出错在哪、给提示，不直接给完整答案。

宝妈

我是两个孩子的妈妈，时间很碎。回答尽量短、分步骤写，每一步5分钟内能做完；涉及孩子用药和健康的，只做整理和参考，并提醒我问医生。

写自己的版本时，记住四个要素：目标（我要什么）、交付（什么格式、放哪）、限制（不能碰什么）、验收（怎样算完成）。用了一两周觉得还啰嗦，就加一句「回答控制在 200 字以内」。

② 生成对话记忆

路径：设置 → 记忆与进化

头像菜单 → 记忆与进化（或 设置 → 记忆与进化）。「生成对话记忆」默认开启，先确认它没被关掉。

记忆每晚整理当天的会话，仅你本人可见；记错了可以点右上角编辑图标，用对话告诉它记住或忘记什么，也可以一键清空。还支持从其他 AI 导入你的使用习惯。

③ 本地技能与记忆沉淀

路径：设置 → 智能体

设置 → 智能体（部分版本叫「技能与智能体」）→ 本地技能与记忆沉淀。

打开后，它会自动记录本地记忆和工作日志，并把反复做的多步骤任务沉淀成技能。数据只保留在你的电脑和工作区里。

④ 技能自动更新

路径：设置 → 智能体

和上一项在同一页，打开「技能自动更新」。

已安装的技能有新版本时会自动升级；按第三方教程的说明，你自己编辑过的技能不会被覆盖。

⑤ 默认工作空间存储路径

路径：设置 → 通用

设置 → 通用（存储相关区域）→ 默认工作空间存储路径 → 更改。

新建任务和工作空间会自动存到这里。建议改到空间充足、你熟悉的位置，比如 D:\WorkBuddy。修改不影响已有数据，旧任务不会自动搬过去。同一区域还能设置对话记录的保留期限（永久 / 90 / 60 / 30 天）。

⑥ 允许锁屏运行

路径：设置 → 通用

设置 → 通用 → 允许锁屏运行。

两档：熄屏后保持唤醒（屏幕照常熄灭、后台任务和远程操控继续，较省电）；保持屏幕常亮（随时能看任务，较耗电）。要挂长任务、或者想出门用手机遥控电脑才需要开。

同在通用里的「运行时防止系统休眠」默认开启：本地任务执行期间电脑不会因空闲自动休眠，建议保持开启。

⑦ 通知提示音

路径：设置 → 通用 → 通知

设置 → 通用 → 通知。

「通知提示音」默认无音效，可选灵动、晴朗、沉稳；「桌面通知」需要到系统设置里允许 WorkBuddy 发通知。任务完成、等你确认、中断时会提醒你，不必一直盯着窗口。

⑧ 手机联动

路径：侧边栏底部「连接移动端」图标

电脑端：鼠标悬停在侧边栏底部的「连接移动端」图标 → 打开「允许移动端连接此设备」。面板里也可以直接打开「保持唤醒状态，以便远程访问」。

手机端：用 WorkBuddy App 登录与电脑相同的账号 → 点侧边栏顶部的设备入口 → 选择这台电脑。建联后关系会保留，以后打开 App 就能看任务进度、补指令、远程停止，任务完成或等待确认时手机也会收到通知。

改完一张清单

• ① 回复风格＋自定义指令：设置 → 个性化

• ② 生成对话记忆：设置 → 记忆与进化

• ③ 本地技能与记忆沉淀：设置 → 智能体

• ④ 技能自动更新：设置 → 智能体

• ⑤ 默认工作空间存储路径：设置 → 通用

• ⑥ 允许锁屏运行：设置 → 通用

• ⑦ 通知提示音：设置 → 通用 → 通知

• ⑧ 手机联动：侧边栏底部「连接移动端」图标

最影响日常效率的是 ①，其余 7 个改一次管很久。

说明：哪些没写、为什么

网上流传的「装好后要改的 8 个配置」里还有「体验优化计划」和「小程序联动」。前者目前只在个别第三方文章里看到，官方帮助文档里没找到对应条目和路径；后者官方文档只写了手机 App 连接电脑，没找到小程序入口。为了不让你对着界面找不到，这两项先不写。界面以你当前版本为准，菜单名不一致时用设置里的搜索框找。

依据：WorkBuddy 帮助中心《系统设置》《记忆》《多端协同（连接电脑）》，腾讯云文档《系统设置》，以及两篇第三方设置教程；核对时间 2026-11-10。
